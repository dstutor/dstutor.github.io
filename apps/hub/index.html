Every tutor is a notebook

Each card is recorded in a different tutor, on its own small dataset.

  • dstutor.org/datascience/
    A Jupyter notebook in your browser Cells that share state, Shift+Enter, Markdown and .ipynb. The code runs in the page: nothing to install.
  • dstutor.org/pandas/
    Step through it, beside your code Each operation becomes a few stages next to the line that ran it: which keys a merge matches, how rows pair, the result.
  • dstutor.org/sql/
    Present mode Teach from the notebook, then fill the screen with the step for lecture and step through it there.
  • dstutor.org/polars/
    Share and save Copy a link that carries the whole notebook, or open and save .ipynb and export the steps as PDF or PNGs.
